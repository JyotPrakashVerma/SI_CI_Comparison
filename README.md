# Simple vs. Compound Interest Calculator

## About

A lightweight browser-based loan calculator that compares simple interest and compound interest costs in Indian rupees. Adjust the loan amount, interest rate, tenure, and compounding frequency to see the total repayment, interest paid, and difference between both loan structures.

## Features

- Compare simple and compound interest side by side
- Live calculations as loan assumptions change
- Indian rupee formatting and lakh/crore-friendly values
- Repayment comparison chart
- Detailed yearly breakdown table
- Responsive layout for desktop and mobile

## Usage

Open `index.html` in a modern web browser. No build step or installation is required.

The page loads Tailwind CSS and Chart.js from their public CDNs, so an internet connection is required for the styling and chart library.

## Built With

- HTML
- Tailwind CSS via CDN
- Chart.js via CDN
- Vanilla JavaScript
